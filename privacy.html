このアプリについて

reko timeline は、開発者本人が自分の記録を振り返るためだけに使う個人用アプリです。開発者以外の利用者はいません。

取得する情報

Google アカウントでの許可を受けて、YouTube Data API を通じて次の情報だけを読み取ります。

  • 本人が YouTube で「高く評価」した動画の一覧(動画のタイトル、チャンネル名、動画ID、高く評価した日時)

権限は読み取り専用(youtube.readonly)です。動画のアップロード、評価の変更、コメントなど、YouTube 上の情報を変更する操作は一切行いません。

使い方と保存場所

読み取った情報は、本人の自宅のコンピュータ上で動く記録アプリの時系列表示にだけ使います。第三者への提供、販売、広告への利用は行いません。認証用のトークンは本人のコンピュータ内にのみ保存します。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

Google API サービスのユーザーデータに関するポリシー

このアプリによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。
